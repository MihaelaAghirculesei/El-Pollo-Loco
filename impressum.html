What this site processes

This is a static website. It sets no cookies and uses no analytics, advertising, embedded media or other third-party services. There is no contact form, no user account and no newsletter.

Server log files. The site is hosted on Cloudflare Pages (Cloudflare, Inc., 101 Townsend Street, San Francisco, CA 94107, USA). Each request is automatically logged by the host with technical access data — IP address, date and time, the file requested, the referrer URL and the browser user agent — in order to deliver the site and keep it secure and stable. Legal basis: Art. 6(1)(f) GDPR (legitimate interest). As the host is based in the USA, this involves a transfer covered by the EU Standard Contractual Clauses; see Cloudflare's privacy policy.

Local storage. The game stores a single value in your browser's local storage — whether the sound is muted — so the setting is remembered between visits. It stays on your device, is never transmitted, and you can clear it at any time through your browser settings.
